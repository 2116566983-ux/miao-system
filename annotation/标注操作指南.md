# 标注操作指南

给教师、助教和参与标注的学生。

**目标**：把 245 个纹样分组的标注字段填完，让检索界面上的地域、技法、色彩等维度真正可用。

---

## 一、为什么是 245 组而不是 1000 张

数据集实测是 **250 张原图 × 4 种变体**（原始图 / 纹理变体 / 色彩变体 / 拼贴合成图），
命名序号 `% 4` 与变体严格对应，校验零例外。

4 个变体在视觉上是**同一张苗绣的不同版本**。所以：

- **标注只做一次**，标在分组上，4 个变体自动共享
- 人工工作量因此是 **245 次**（5 组因原图过小由其他变体代替），不是 1000 次

这就是图模型里把标注属性挂在 `MotifGroup` 而不是 `Image` 上的原因。

---

## 二、怎么填（两种方式，推荐第一种）

### 方式一：在网页里标注 ⭐ 推荐

打开系统的 **④ 标注纹样** 标签页，全程点击操作，不需要编辑任何文件：

1. 填上自己的**学号 / 姓名**（用于统计每个人的标注量）
2. 页面会自动显示一个纹样图，右侧是标注表单
3. 看图标选题材、地域、技法、主色调
4. 点「**保存并看下一组**」，自动跳到下一个未标注的
5. 顶部进度条实时显示完成度

**优点**：

- 图片直接显示，不用自己去文件夹里找
- 下拉选项来自本指南的推荐取值，不用记
- 机器参考值就显示在图片旁边，方便对照
- 一组只需标一次，**4 个变体自动继承**
- 不会因为编码、逗号、换行把 CSV 弄坏

**看不到图或没有下拉选项**？找教师确认图片目录是否配置正确。

### 方式二：命令行填表（适合批量 / 离线）

如果习惯用 Excel 一次性处理几百行，用这个方式。

---

## 三、文件在哪（方式二用）

| 文件 | 用途 |
|---|---|
| `annotation/annotation_sheet.csv` | **主表**，含机器参考值，标注时对照着看 |
| `annotation/annotation_sheet_slim.csv` | 精简表，只有待填字段，适合导出分发 |
| `annotation/annotations.csv` | **网页标注的数据**（自动生成，含标注人与时间戳） |

前两张是命令行方式的表，第三张是网页方式自动产生的。
两种方式不冲突，但**不建议混用**，容易搞不清哪份是最新的。

### 列的构成

- **前 8 列**：编号、文件名、尺寸、方向、组内图片总数、其中可标注数 —— 只读
- **中间 11 列**：标为 `【待填】` —— **需要你填**
- **后 8 列**：标为 `【参考】` —— 机器统计，**仅供参考，不要直接采信**

---

## 四、怎么填（方式二）

1. 打开 `annotation_sheet.csv`（用 Excel 或 WPS）
2. 按「文件名」找到对应图片，打开看
3. 填写 `【待填】` 的 11 列
4. 保存为 CSV（**保持 UTF-8 编码**）
5. 运行合并脚本

### 填写原则

- **只填你确定的**。不确定就留空，留空不会出错，填错才会
- **优先填前 4 项**（纹样类型、地域、技法、主色调），这四项决定检索界面的可用性
- 后 7 项（构图特征、文化寓意、质量备注、纹样细类、适用说明）属于加分项，可后补

---

## 四、字段定义与取值参考

### 【必填级】前 4 项

#### 1. `pattern_type` 纹样类型

苗绣常见纹样类型，建议从下列取值中选（可自拟）：

| 取值 | 说明 |
|---|---|
| 花卉纹 | 牡丹、莲花、石榴花、桃花等植物题材 |
| 动物纹 | 蝴蝶、鱼、鸟、龙、凤、麒麟等 |
| 几何纹 | 回纹、万字纹、菱形、方格、铜鼓纹 |
| 人物纹 | 神话人物、生活场景人物 |
| 星辰纹 | 太阳、星辰、云雷纹 |
| 文字纹 | 福、寿、喜等字样 |
| 组合纹 | 两种以上题材组合 |

#### 2. `region` 地域来源

苗绣地域性很强，不同支系风格差异明显：

| 取值 | 代表特征 |
|---|---|
| 贵州黔东南 | 台江、雷山一带，破线绣、辫绣发达，蝴蝶妈妈题材多 |
| 贵州黔南 | 都匀、三都，水族马尾绣影响 |
| 贵州毕节 | 纳雍、织金，几何纹与十字绣较多 |
| 贵州安顺 | 屯堡风格，与汉族纹样交融 |
| 湖南湘西 | 花垣、凤凰，配色偏艳丽 |
| 云南文山 | 与壮族、彝族纹样交融 |
| 广西融水 | 与大苗山支系相关 |
| 未确定 | **不确定时填这个，别猜** |

#### 3. `technique` 刺绣技法

| 取值 | 特征 |
|---|---|
| 平绣 | 最常见，丝线平铺，表面平整有光泽 |
| 锁绣 | 线圈环环相扣，呈辫状链条 |
| 破线绣 | 一根丝线劈成多股再绣，极细腻 |
| 辫绣 | 先编成辫带再钉绣，有立体感 |
| 绉绣 | 丝线搓成绉纹状，表面凹凸 |
| 堆绣 | 布片折叠堆叠，立体效果 |
| 数纱绣 | 按布纹数格子下针，几何感强 |
| 十字绣 | 十字交叉针法 |
| 马尾绣 | 丝线缠绕马尾作芯，水族特色 |
| 打籽绣 | 针脚打结成籽粒状颗粒 |
| 未确定 | **不确定时填这个** |

> ⚠️ 技法**无法从像素推断**，机器帮不了。这是最需要人工判断的一项。
> 如果只能看照片、没有实物信息，宁填「未确定」。

#### 4. `dominant_color` 主色调

**人眼判断画面里最主要的颜色**，不要用机器那列。

常用取值参考：靛蓝 / 藏青 / 深蓝 / 黑色 / 白色 / 朱红 / 桃红 / 玫红 /
深绿 / 墨绿 / 翠绿 / 明黄 / 土黄 / 紫色 / 深褐

> ⚠️ 特别注意：这批图**普遍带黑色边框或暗背景**，机器统计的第一位常常是
> 背景色而非纹样主色。例如一张桃红花卉刺绣，机器会报「黑色」。
> **请以纹样本身的颜色为准。**

---

### 【加分项】后 7 项

#### 5. `symmetry_type` 对称形式

| 取值 |
|---|
| 左右对称 / 上下对称 / 双向对称 / 近似对称 / 非对称 |

机器参考列 `【参考】机器预判对称` 给了初判，但它算的是**整幅图像的镜像相似度**，
而照片的拍摄角度、光照、布料褶皱都会拉低这个值，所以**误差较大**。
建议以人工判断为准，机器值只作提示。

#### 6. `composition` 构图特征

自由填写。可参考：中心对称式 / 二方连续 / 四方连续 / 散点式 / 满构图 / 边饰环绕

#### 7. `cultural_meaning` 文化寓意

自由填写。苗绣纹样多有寓意，例如：

- 蝴蝶妈妈 —— 苗族创世神话中的始祖
- 石榴 —— 多子多福
- 鱼 —— 年年有余、生殖繁衍
- 铜鼓纹 —— 权力与祭祀

> 不确定就留空。**不要编造寓意**，这属于民族文化内容，编错比留空严重。

#### 8. `permission_note` 来源与授权

**这一项关系到能否公开展示，务必认真对待。**

要写清楚：

- 图片从哪来（自己拍摄 / 博物馆 / 网络 / 他人提供）
- 授权范围（可教学使用 / 可公开展示 / 仅内部参考）
- 是否可商用

**来源不明或未授权的图片，公开展示前必须处理。**

#### 9. `quality_note` 质量备注

自由填写。例如：清晰度不足 / 有反光 / 局部模糊 / 背景杂乱

#### 10. `pattern_type_detail` 纹样细类

比 `pattern_type` 更细的分类。例如 `pattern_type` 填「花卉纹」，
这里可填「牡丹」。

#### 11. `usage_suggestion` 适用说明

这件纹样适合用在哪类创作任务。例如：适合做单图重组的基础素材 /
纹样结构完整，适合多纹样组合的主角。

## 五、填完之后

### 1. 合并回主数据

```bash
cd miao-system
python build_annotation_sheet.py merge
```

脚本会：

- 显示各字段的填写进度百分比
- 把人工填的值写回 `metadata/images.csv`
- **主色调和对称形式如果人工留空，会用机器参考值兜底**（聊胜于无）

### 2. 重新生成图数据库导入文件

```bash
python build_graph_csv.py --src metadata/images.csv --out graph/csv
```

### 3. 重新导入图数据库

```bash
cypher-shell -u neo4j -p 你的密码 -f graph/import.cypher
```

### 4. 重启系统

标注完成后，检索界面上就能按地域、技法、色彩筛选了。

## 六、分工建议（对应方案的 32 课时安排）

| 角色 | 做什么 | 工作量 |
|---|---|---|
| **教师** | 确定取值口径、审核地域与技法、处理授权字段 | 前期定标准 |
| **助教 / 计算机专业学生** | 批量填 `pattern_type`、`composition`、`quality_note` | 约 245 组 |
| **学生** | 分成小组，每组负责一部分分组的色彩与构图判断 | 第一单元实验 |
| **机器** | 提供对称、明度、疏密等参考值 | 已自动生成 |

**这正好对应方案里的「苗绣纹样数据整理实验」** —— 学生在这个过程中学到的
不只是填表，而是"数据从哪来、字段怎么定义、不确定时怎么处理"这套数据素养。

## 七、注意事项

1. **编码**：CSV 必须保存为 UTF-8，否则中文会乱码。Excel 另存时选「CSV UTF-8」
2. **不要改列名**，不要增删列，否则合并脚本会出错
3. **不要改前 8 列的编号**，那是数据关联的依据
4. **留空是允许的**，脚本会跳过空值；填错才会污染数据
5. **民族文化内容谨慎对待**：寓意、地域这类字段涉及民族文化的准确表达，
   不确定就留空或填「未确定」，不要凭印象填写
