# 免费云端生图 API 接入指南

本文档说明如何用一个免费云端 API 让系统具备 AI 生成能力——**不需要装 ComfyUI、不需要下模型、不需要 GPU**。

---

## 一、为什么有这个方案

系统的生成环节原本只支持本地 ComfyUI，但那条路有门槛：

| | 本地 ComfyUI | 免费云端 API |
|---|---|---|
| 一次性下载 | 本体 2GB + 模型 4–7GB | 无 |
| 硬件要求 | NVIDIA 显卡 6GB 显存以上 | 无 |
| 装机耗时 | 1–3 小时（含模型下载） | 5 分钟 |
| 出图速度 | 10–20 秒/张（RTX 4060） | 10–60 秒/张（排队） |
| 长期成本 | 电费 | 免费额度内 0 元 |
| 稳定性 | 完全可控 | 免费服务无 SLA，高峰期可能排队 |
| 隐私 | 数据不外传 | 素材会传到第三方 |

**结论**：临时演示、外出讲课、学生自己在家练手 → 云端 API 更省事。
长期开课、要求稳定和可控 → 本地 ComfyUI 更好。

两者可以随时切换，代码不用改。

## 二、推荐：魔搭 ModelScope

### 为什么选它

- **国内直连**，不需要梯子
- **有真正的每日免费额度**，不是"试用一次"那种
- **中文提示词支持好**——苗绣这类题材用中文描述更准确
- 图生图模型 `Qwen/Qwen-Image-Edit` 与我们的需求完全对口

### 其他渠道的现状（2026-10-13 核实）

网上很多"免费生图 API"的文章已经过时了，这里列清楚避免白折腾：

| 服务 | 现状 |
|---|---|
| **ModelScope 魔搭** | ✅ 每日免费额度，需阿里云实名 |
| Cloudflare Workers AI | ⚠️ 有免费额度，但需注册海外账户，国内访问不稳 |
| Pollinations | ❌ 已改为需 key + 付费 credits |

## 三、接入步骤（约 5 分钟）

### 第 1 步：注册并实名

1. 打开 https://modelscope.cn
2. 用手机号或邮箱注册
3. **绑定阿里云账号并完成实名认证**（不做这步调用会返回 401）

### 第 2 步：获取 API Key

1. 登录后，鼠标移到右上角头像 → 「访问令牌」
2. 点「新建访问令牌」，起个名字（例如 `miao-system`）
3. **立刻复制保存**，页面关掉后不再显示

### 第 3 步：配置环境变量

**Windows（命令行）**：

```bash
set IMAGE_API_KEY=你的密钥
```

**Windows（永久生效，推荐）**：

```powershell
[Environment]::SetEnvironmentVariable("IMAGE_API_KEY", "你的密钥", "User")
```

设完后**需要重开命令行窗口**才生效。

**macOS / Linux**：

```bash
export IMAGE_API_KEY="你的密钥"
```

要永久生效，把这行加到 `~/.bashrc` 或 `~/.zshrc`。

### 第 4 步：验证

```bash
python check_env.py
```

看到这一段就成功了：

```
[后端 B] 免费云端生图 API
  接口地址：https://api-inference.modelscope.cn/v1
  使用模型：Qwen/Qwen-Image-Edit
  密钥状态：已配置
  [可用] 密钥有效，接口可用
```

### 第 5 步：启动系统

```bash
streamlit run app/streamlit_app.py
```

界面右上角徽标会变成 **「生成可用 · 云端 API」**。

## 四、环境变量完整列表

| 变量 | 必填 | 默认值 | 说明 |
|---|---|---|---|
| `IMAGE_API_KEY` | ✅ | 无 | API 密钥 |
| `IMAGE_API_BASE` | | ModelScope 地址 | 换成其他服务时填 |
| `IMAGE_API_MODEL` | | `Qwen/Qwen-Image-Edit` | 图生图模型 |
| `IMAGE_API_PROVIDER` | | `modelscope` | 预设服务商 |

### 切换模型

想换成文生图（不传参考图）：

```bash
set IMAGE_API_MODEL=Qwen/Qwen-Image
```

想接其他 OpenAI 兼容服务（如自建、其他云厂商）：

```bash
set IMAGE_API_BASE=https://你的服务/v1
set IMAGE_API_KEY=你的密钥
set IMAGE_API_MODEL=模型名
set IMAGE_API_PROVIDER=openai_compat
```

## 五、系统是怎么用这个接口的

### 单图重组

把学生选中那张苗绣纹样作为**参考图**，连同提示词一起发给接口：

```
参考图（纹样原图） + "将这幅苗绣纹样重新演绎为现代设计风格..." 
        ↓
   生成新作品
```

### 多纹样组合

**这里有个务实的取舍**，你要知道：

多数云端图生图接口**只接受一张参考图**。所以两图组合时，系统的做法是：

- 用第 1 张作为参考图
- 把第 2 张的编号写进提示词，描述"融合两种纹样的构图与配色"

**这意味着组合效果不如本地 ComfyUI**——ComfyUI 是真的把两张图画布混合，云端 API 只是文字描述。如果结题报告要展示"多纹样融合"的技术含量，建议用本地 ComfyUI 演示这个功能。

## 六、常见问题

### 返回 401

密钥错误，或**账号没做实名认证**。ModelScope 要求绑定阿里云并实名，否则一律 401。

### 返回 429

免费额度用完了。额度**每日 0 点（北京时间）重置**，不支持累计。等第二天即可。

### 提示"接口不可用：未配置 API 密钥"

环境变量没生效。检查：

1. 变量名是 `IMAGE_API_KEY`，不能拼错
2. 设完是否**重开了命令行**
3. 用 `echo %IMAGE_API_KEY%`（Windows）确认能打印出来

### 生成很慢 / 一直在等

免费服务高峰期要排队，这是正常的，**没有 SLA 保障**。系统超时设的是 180 秒，超了会报错让你重试。

如果课堂上要保证速度，用本地 ComfyUI。

### 生成结果不理想

云端用的是通用图像编辑模型，对苗绣这种特定风格的把握不如专门微调过的模型。可以：

1. **改提示词**——描述得更具体（"苗族刺绣，平绣技法，红蓝配色，对称构图"）
2. **调参考图**——选主体清晰、背景干净的素材
3. 换本地 ComfyUI + 专门的 LoRA 模型

### 免费服务突然不可用了

有可能。免费服务无承诺，可能改政策、限流、甚至下线。系统的设计是**任何时候挂了都只是降级，不会崩**——检索和归档照常工作。

要长期稳定，请用本地 ComfyUI。

---

## 七、隐私提醒

用云端 API 意味着**学生选中的苗绣素材会上传到第三方服务器**。

- 如果素材是公开的纹样图片，通常没问题
- 如果涉及合作方提供的**未公开素材或有版权约定**的图片，请先确认授权范围
- 教学场景建议在课程说明里告知学生这一点

本地 ComfyUI 没有这个问题，数据不出机器。

---

## 八、想换回本地 ComfyUI

不用改代码。启动 ComfyUI 后，系统**自动优先使用本地**（因为本地排在优先级前面），徽标会变成「生成可用 · RTX 4060 8GB」。

安装步骤见 `docs/comfyui-guide.md`。

如果想强制用云端，把 ComfyUI 关掉即可。
