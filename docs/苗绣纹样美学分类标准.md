# 苗绣纹样美学分类标准（v1.0）

> 依据：2026-10-19 项目研讨会议「建立纹样分类标准」要求
> 数据：1250 张 basic 原图（5 类 × 250），来自 `数据集.zip → archive/newdata_en`
> 产出：`metadata/纹样三维分类清单.csv`、`metadata/美学数学分类.csv`
> 工具：`tools/classify_aesthetics.py`（含 12 项合成图自检）

---

## 1. 这份标准补的是哪一维

数据包里 10-17 已完成两级分类，回答的是「它是什么纹样、什么配色」：

| 已有维度 | 内容 | 来源 |
|---|---|---|
| 艺术分类 | 花卉植物纹 / 几何对称纹 / 动物神兽纹 / 卷草涡纹 / 其他 | 10-17 交付 |
| 配色分类 | 地色档（明度×色相族）+ 花色档（多彩/素彩） | 10-17 交付 |

会议追加要求的是**几何与构图**这一维 ——
「结合对称美、流线型、黄金分割等数学逻辑，对苗绣纹样进行拆解、提取与分类」。

所以本标准的输出是三张表可拼在一起的**三维分类**：

```
艺术分类（是什么题材）  ×  配色分类（什么色）  ×  美学分类（什么几何结构）
                                    ↓
                          产品形态倒推（适合做成什么）
```

合并结果见 `metadata/纹样三维分类清单.csv`，1250 行，三套标签逐图对齐。

## 2. 三个维度的定义与算法

所有指标都在 `tools/classify_aesthetics.py` 里用 **numpy + PIL 手写**，
环境里没有 scipy / cv2 / skimage（连大津阈值、自相关、极坐标采样都是自己实现的）。

### 2.1 对称美 —— 分两把尺子

| 指标 | 定义 | 判定 |
|---|---|---|
| `sym_mirror` | 在**拆解出的主体**上做左右/上下/180°翻转，归一化残差 = 1 − 平均绝对差 / 主体自身起伏 | ≥ 0.60 判镜像对称 |
| `sym_radial` + `rot_fold` | 以结构能量重心为极点做极坐标采样，看径向剖面旋转 2π/k 后的自相关；k 取「达标的**最大**值」 | ≥ 0.50 且瓣数 ≥ 3 判放射对称 |
| `periodic` | 高通滤波后做二维归一化互相关，找最强平移重复 | ≥ 0.75 判连续重复 |

**为什么必须两把尺子**：把实物照片做镜像差异（`docs/img/镜像差异诊断.png`）
能直接看到，团花的差异图本身呈对称的蝴蝶纹 —— 说明布局是**绕中心转出来的**，
不是左右对折出来的。只量镜像会把整批团花判成"不对称"，那是尺子错了。

### 2.2 流线型

| 指标 | 定义 | 含义 |
|---|---|---|
| `dir_entropy` | 边缘方向直方图的归一化熵（24 档，按梯度幅值加权） | 高 = 方向分散 = 有机曲线；低 = 方向集中 = 几何直线 |
| `angular_var` | 方向角场的空间变化率，用双角 (cos2θ, sin2θ) 表示避免 ±π 跳变 | 曲率的代理量 |

两者合成 `curl_tercile`（熵 0.6 + 曲率 0.4），按批内三分位分「高/中/低」。

### 2.3 黄金分割

| 指标 | 定义 |
|---|---|
| `fill` | 主体像素占整幅画面的比例 |
| `golden_fill` | `fill` 贴近 0.382 或 0.618 的程度（两者是同一分割关系的两面） |
| `golden_center` | 主体重心落在 0.382/0.618 分割线附近的程度 |
| `golden` | 0.6 × `golden_fill` + 0.4 × `golden_center` |

## 3. 实测结果（n = 1250）

### 3.1 指标分布

| 指标 | 均值 | 标准差 | 最小 | 最大 |
|---|---|---|---|---|
| `sym_mirror` | 0.093 | 0.134 | 0.000 | 0.899 |
| `sym_radial` | 0.260 | 0.159 | 0.000 | 0.876 |
| `sym_best` | 0.279 | 0.161 | 0.000 | 0.899 |
| `periodic` | 0.201 | 0.111 | 0.039 | 0.687 |
| `dir_entropy` | 0.969 | 0.041 | 0.676 | 0.999 |
| `angular_var` | 0.649 | 0.154 | 0.243 | 1.220 |
| `fill` | 0.543 | 0.168 | 0.101 | 0.949 |
| `golden` | 0.811 | 0.107 | 0.373 | 0.994 |

### 3.2 标签分布

| 对称型 | 数量 | 占比 |
|---|---|---|
| 自由式 | 1211 | 97% |
| 连续重复 | 15 | 1% |
| 放射对称 | 15 | 1% |
| 左右/上下/中心对称 | 9 | 1% |

| 流线强度 | 高 309（25%）｜中 633（51%）｜低 308（25%） |
|---|---|
| **黄金贴合** | 高 417（33%）｜中 417（33%）｜低 416（33%） |

> **「自由式 97%」不是算法失败，是这批资料的客观特征。**
> 它们不是矢量纹样图，而是**手绣成品的实物照片**：主体不居中、带黑边或衬布、
> 有透视与光照差异、每一针手绣都不完全一样。
> 所以严格满足几何对称或平移重复的不足 4%。
>
> 因此表格的用法是：**类别标签只标注"确证"的少数，日常选图用连续分数排序**
> （`sym_best` / `golden` / `curl_tercile`），配合 `sym_grade` 高/中/低。
> 这恰好印证了会议的判断：原始纹样必须经过「拆解、提取」才能用于二次创作 ——
> 对称性在实物照片层面本来就是残缺的，需要在下游设计里重建。

### 3.3 抽检

- 15 张「放射对称」全数人眼复核：均为圆形团花、放射花心、角花四向排布，判定成立。
- 15 张「连续重复」全数复核：菱形格、重复花边、重复小 motif，判定成立。
- 拼图：`docs/img/美学分类抽检.png`（上排放射组、下排重复组，各 15 张全数复核）

## 4. 产品形态倒推

按会议「先定最终作品形态，再倒推纹样主题」的要求，用可解释规则打分
（不是训练出来的模型，权重写在 `classify_aesthetics.py` 里，可随时改）：

| 产品 | 打分规则 |
|---|---|
| 包袋面料 | 0.55 × 可平铺程度 + 0.45 × 疏密居中程度 |
| 钥匙扣徽章 | 0.45 × 对称强度 + 0.35 × 主体集中 + 0.20 × 轮廓干脆 |
| 潮玩娃娃摆件 | 0.45 × 具象叙事性 + 0.35 × 流线卷曲度 + 0.20 × 对称强度 |

结果分布：潮玩娃娃 531（42%）、包袋面料 391（31%）、钥匙扣徽章 328（26%）。

### 4.1 艺术类 → 产品（交叉表）

| 艺术类 | 首选产品（占比） |
|---|---|
| 花卉植物纹 | 潮玩娃娃 47%，包袋 32%，钥匙扣 22% |
| 几何对称纹 | **钥匙扣 45%**，包袋 38%，潮玩 17% |
| 动物神兽纹 | **潮玩娃娃 97%**，包袋 2%，钥匙扣 1% |
| 卷草涡纹 | **包袋面料 47%**，钥匙扣 28%，潮玩 25% |
| 其他 | 包袋 38%，钥匙扣 36%，潮玩 27% |

三条结论与常识一致，可直接用于选品：

1. **具象的动物神兽几乎全部指向潮玩娃娃** —— 有形象、有故事，适合立体化。
2. **几何对称纹指向钥匙扣徽章** —— 小面积、强秩序，缩小不失真。
3. **卷草涡纹指向包袋面料** —— 连续卷草天然适合铺开。

### 4.2 配色与产品

| 产品 | 高频配色 |
|---|---|
| 包袋面料 | 墨黑地·素彩 56、墨黑地·红彩 38、墨黑地·多彩 33 |
| 钥匙扣徽章 | 素白地·素彩 39、墨黑地·多彩 31、墨黑地·素彩 27 |
| 潮玩娃娃 | 玫红调·红彩 52、浅彩地·红彩 48、墨黑地·素彩 43 |

潮玩类明显偏向**红调 + 浅彩地**（更讨喜、更年轻），包袋类偏**墨黑地**（耐脏、传统）。

## 5. 一个独立的交叉验证

流线维度没有用任何类目标签做训练，但算出来的结果自己认出了它该认出的那一类：

| 艺术类 | 流线「高」占比 |
|---|---|
| 卷草涡纹 | **52%** |
| 几何对称纹 | 26% |
| 动物神兽纹 | 24% |
| 花卉植物纹 | 18% |
| 其他 | **3%** |

卷草涡纹本就是曲线纹样，几何类与"其他"（多为平绣画框）最低 ——
指标测的确实是"曲不曲"，而不是别的东西。

## 6. 踩过的坑（三条，都是靠自检抓出来的）

| # | 错误做法 | 现象 | 修正 |
|---|---|---|---|
| 1 | 对称度直接量整幅画面 | 全体接近 0，连"几何对称纹"也只有 0.05 | 先按前景密度拆主体再量；团花改用放射对称 |
| 2 | 周期性用一维均值剖面自相关 | 84% 被判"连续重复"，去趋势后 0.79→0.12 | 改二维归一化互相关 + 高通 + 裁边 |
| 3 | 黄金比放在裁剪后的主体上算 | 裁完占比恒为 1.0，`golden_fill` 算成 0 | 黄金比量整幅构图，只在全幅上算 |

`--selftest` 里 12 条断言对应这些坑：偏置对称图、光滑渐变图、
棋盘格、六瓣团花、前景占 38.2% 的方块……每条都有已知答案。

```bash
python tools/classify_aesthetics.py --selftest    # 先证明算法没写反
python tools/classify_aesthetics.py               # 再跑全量
```

## 7. 局限与下一步

**局限**

1. 指标在**实物照片**上算，透视、光照、手绣差异都会压低对称与重复的检出率；
   若将来拿到矢量图或正射扫描图，同一套算法会灵敏得多。
2. `period_px`（重复周期像素数）只是近似值，采样在 128px 网格上，
   误差约 ±2 格；轴向（横向/纵向/四方）比具体数值可靠。
3. 产品倒推是**规则打分**，不是机器学习模型。权重可调，
   换一批数据或换商业目标时应重新标定。
4. 「自由式」占 97%，说明这一维只能做**排序**，不适合做筛选门槛。

**下一步建议**

1. 把 `sym_grade` / `stream_label` / `product` 三列接进系统检索页做筛选项；
2. 用 `rot_fold` 作为「团花纹样」的自动标签，供 ② 页生成时优先推荐圆形构图模板；
3. 若要提升对称检出，考虑先在提取阶段做透视矫正与主体居中（④ 页已有拆解能力，
   可直接复用 `motif_extract` 的掩膜），再算指标。
