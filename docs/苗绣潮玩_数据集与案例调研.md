# 苗绣纹样 × 现代潮玩：数据集与案例调研

> 对应会议待办：「搜索苗绣纹样与现代潮玩、卡通人物等现代图案相结合的数据集与案例」
> 调研日期：2026-10-19　｜　调研人：杨帆　｜　用途：② AI 重组创作页与产品选品
>
> 本文事实分两级：标「已核对」的均打开原文逐条比对；只有二手来源的另列在 §5。

---

## 0. 三句话结论

1. **没有现成的「苗绣 × 潮玩」配对数据集**（搜遍 Kaggle / HuggingFace / GitHub / LiblibAI 均无）。
   能做的是两条：用 CC0 的苗族纹样库补素材，再用「纹样 LoRA + 潮玩载体」拼出来。
2. **最硬的对标是一家贵州企业**：舞水云台（施秉）已建自己的 AI 训练数据库，
   把苗绣设计周期从 10–14 天压到 **1–2 天**，并且拿到了世界杯官方授权做陆冲板/箱包/挂坠。
   这说明「AI + 苗绣 + 潮玩品类」这条路别人已经走通了，我们不是空想。
3. **现成的苗绣 LoRA 不能直接用于商用**：公开的那几个都是「苗族服饰人物写真」向，
   不是纹样；其中 LiblibAI 那个的许可栏同时写着「商用」与「生成内容不可商用」，
   自相矛盾，不能当授权凭据。纹样向的必须自己训 —— 但配方有现成的（见 §1.4）。

### 1.4 那篇苗绣论文的完整参数（已打开原文逐条核对）

这是目前**唯一一篇**「苗绣 + 扩散模型 + 实物绣制验证」都做了的公开研究，参数可以直接照搬：

| 项目 | 原文数据 |
|---|---|
| 数据量 | **329 张**照片（晚清至当代），来自传承人、私人收藏、博物馆 |
| 分类 | 五类绣法：锡绣 40 / 破线绣 90 / 打籽绣 58 / 绉绣 78 / 贴布绣 63 |
| 增强 | 每种绣法扩到 **500 张** |
| 底座 | Stable Diffusion **1.5** + **LoRA**（dim=32、alpha=32、AdamW8bit） |
| 学习率 | U-Net `1e-4`，文本编码器 `1e-5`；10 轮、批 1、bf16 |
| **训练硬件** | **RTX 3060 Ti / 16GB 内存，每种绣法约 1 小时** |
| 标注 | 5 个维度（绣法/母题/造型/色彩/纹理），5 位 60 岁以上传承人指导 + WD14 自动标注后人工校正 |
| 评估 | 客观 FID + 10 位专家五点量表（造型/色彩/纹理/艺术价值/创造性/应用潜力） |
| FID 改善 | 总体 **177.82**，优于 SD v1.5 / SDXL / DALL·E 3 / Midjourney；锡绣改善最大 308.88 → 108.49 |
| 推荐参数 | LoRA 权重 0.8–1.2，采样步数 20–40 |
| 实物验证 | 选锡绣、破线绣两种，用 **ZSK JF-0215-495 工业绣花机** + GiS BasePac 10 软件织出实物 |

**两条对我们最有用的结论：**

1. **RTX 3060 Ti 就能训，每种绣法 1 小时**——我们的 4060 8GB 完全够，不必等 A100。
2. 论文把苗绣商业化分成三条路：纯手工（收藏级）、**手工+机器（文创产品）**、纯机械（批量）。
   我们的系统落在第 2 条，这与案例侧观察到的「机器做量、绣娘做精修」完全一致（见 §2.1 舞水云台）。

## 3. 对我们系统的落地建议

### 3.1 ② 生成页的 prompt 改成「五段式」

照抄 IoC Lab 已验证的结构，正好和我们上一轮做的分类**天然对接**：

```
[纹样类型] + [构图] + [配色] + [题材] + [中心元素]
```

| 槽位 | 填什么 | 我们已有的数据 |
|---|---|---|
| 纹样类型 | 花卉植物纹 / 几何对称纹 / 动物神兽纹 / 卷草涡纹 | 艺术分类（现成） |
| **构图** | 圆形放射 / 方形对称 / 异形自由 | **`sym_label` + `rot_fold`（现成！团花几瓣可以直接填）** |
| 配色 | 墨黑地·素彩 / 玫红调·红彩 … | 配色分类（现成） |
| 题材 | 蝴蝶妈妈 / 龙纹 / 鱼鸟纹 … | 需补：纹样语义标签 |
| 中心元素 | 一朵花 / 一只鸟 | 需补 |

**这张表说明一件事**：我们不需要再找数据集才能开工——分类结果本身已经是可用的 prompt 生成器。

已经做成可运行模块：`app/prompt_schema.py`

```bash
python app/prompt_schema.py     # 自带 7 条自检 + 按类别抽样打印提示词
```

真实输出（`mx/basic_0.jpg`，动物神兽纹 / 潮玩娃娃）：

```
苗绣纹样；大量留白，主体小而集中，局部有严谨的呼应结构；墨黑地底布，红彩的花色；
以蝴蝶、鸟、鱼、龙等图腾形象为主体；线条流动、构图考究，接近传统绣样的成熟章法；
做成 12cm 立体摆件贴图，需有正面的完整形象。
⚠ 原图主体仅 633 像素，而潮玩娃娃摆件需要 945 像素，直接生成会糊；建议先放大或矢量重绘
```

注意那个警告：模块会自动核对 §3.2 的分辨率数据，撑不住的直接提示，
避免学生拿到糊图以为是自己提示词写错了。

### 3.2 产品形态优先「小载体」

结合上一轮算出的分辨率结论（见 `docs/苗绣纹样美学分类标准.md` §4.3）：

| 产品 | 分辨率够用比例 | 建议 |
|---|---|---|
| 钥匙扣徽章（3.5cm） | **62% 够** | 优先做 |
| 包袋面料（10cm 单元） | 30% 够 | 次选 |
| 潮玩娃娃（12cm 贴图） | **仅 8% 够** | 现有图库撑不住 |

所以「娃衣、挂件、徽章」不只是案例里的流行做法，**也是我们现有素材唯一撑得住的品类**。
要做整只潮玩，必须先补高分辨率图（§1.1 的 CC0 库可补）或做矢量重绘。

### 3.3 训练数据量不用贪多，而且不需要 A100

论文用 **329 张**就训出了可用的苗绣 LoRA，**RTX 3060 Ti 上每种绣法约 1 小时**。
我们现有 1,000 张 basic 图已超过这个量级，4060 8GB 也够训——
**先训一版比继续找数据更划算**，A100 留给生成和批量任务。

### 3.4 补一套「纹样语义标签」

案例里所有成功产品都在讲**故事**（蝴蝶妈妈＝祖先、太阳花＝坚韧），
但我们的表里只有几何与配色，没有「这个纹样代表什么」。
建议下一轮补一列 `symbol_meaning`，来源可用 §1.2 的 Wényàng 元数据（注意非商用）作起点。

## 4. 风险与空白

| 风险 | 具体说明 |
|---|---|
| **许可** | Wényàng 是 CC BY-NC（禁商用）；LiblibAI 苗族 LoRA 的许可栏**自相矛盾**（同时写「商用」与「生成内容不可商用」），不能当授权依据；Kaggle 标 CC0 但来源多方，商用需逐张复核 |
| **文化失真** | AI 生成容易把符号用错语境（蝴蝶妈妈不是普通蝴蝶纹）。建议在 prompt 里锁死「必须保留的核心符号」，并在 ⑤ 标注页加一列「符号含义」由人确认 |
| **分辨率** | 现有库做潮玩类产品 87% 不够（需 945px，主体中位 391px） |
| **空白** | 没有任何公开的「苗绣 × 潮玩」配对数据；也没有可商用的苗绣纹样 LoRA。这两块要么自建，要么放弃 |
