## 递进关系

```
实验一：认清数据
  「照片 ≠ 纹样，最关键的字段计算机填不了」
      ↓
实验二：组织数据
  「关系密集的场景，图比表更自然」
      ↓
实验三：使用数据
  「加工是近似不是测量；AI 是取舍不是自动」
      ↓
实验四：表达数据
  「过程即成果；数据永远不够」
      ↓
  ── 回到实验一，开始下一轮 ──
```

**这不是四个独立的实验，是一条完整的数据工作流。**

## 每份指导书的结构

四份文档采用统一结构，教师可直接当教案用：

| 章节 | 内容 |
|---|---|
| 一、这个实验要回答什么 | 一个**可讨论的命题**，不是知识点罗列 |
| 二、预备知识 | 必要的概念，含**反例与边界说明** |
| 三、实验步骤 | 可操作，含**思考题**（不是纯操作步骤） |
| 四、实验作业 | 必做 + 选做（分层，对应路线图的两类学生） |
| 五、提交要求 | 含评分权重 |
| 六、教师备课提示 | 认知重点、常见卡点、时间分配 |
| 附 | 概念速查 / 代码参考 / 与后续实验的衔接 |

## 分层设计（对应路线图第五章）

路线图提出面向两类学生的分层路线，实验作业里已体现：

**共同基础层**（所有学生必做）
- 使用界面完成采集、标注、检索、生成
- 理解每个环节的**判断依据**
- 产出：标注数据 + 作品集 + 说明文档

**技术拓展层**（选做部分）
| 实验 | 拓展内容 |
|---|---|
| 一 | 写 Python 脚本统计字段分布、验证命名规律 |
| 二 | 完整写出 SQL 对照、自己装 Neo4j、设计新节点 |
| 三 | 读源码找阈值、设计改进方案、失败案例分析 |
| 四 | 统计分析、AI 痕迹识别、设计评级字段 |

## 依赖关系与降级方案

| 依赖 | 影响 | 没有时的方案 |
|---|---|---|
| ComfyUI / 云端 API | 实验三步骤 5–6、实验四作品 | 教师演示，或课后完成 |
| Neo4j | 实验二的「真实 Cypher」体验 | 系统自动用 CSV 内存图，**功能与结果一致** |
| 图片目录 | 全部实验 | 系统会明确提示路径问题 |

> **教学设计上的关键**：所有实验的**核心认知目标**
> 都不依赖外部服务。即使课堂没有 GPU，
> 实验一到步骤 4、实验二全部、实验三步骤 1–4
> 都能完整完成。

## 教师快速上手

### 首次开课前

1. 确认图片目录（`python check_env.py` 会自检）
2. 决定是否装 Neo4j（不装也能上，见 `docs/技术文档.md` §6.5）
3. 生成标注任务表：`python build_annotation_sheet.py`
4. 通读四份指导书的「六、教师备课提示」

### 课堂环境

```bash
# 启动系统（Windows 双击 start.bat 即可）
streamlit run app/streamlit_app.py

# 若要用真实图数据库，先启动它（双击 tools/start_neo4j.bat）
```

学生只需要浏览器访问即可，**不需要装任何软件**。

### 标注数据是硬依赖

实验三、四的「检索维度可用」和「数据完备性分析」，
依赖**标注数据**（245 组）。建议：

- 实验一布置 10 组
- 实验二布置 20 组
- 全班合计即可覆盖相当比例

查看进度：**⑤ 标注纹样** 页面顶部有进度条。
