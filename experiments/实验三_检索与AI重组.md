# 实验三 · 纹样检索与 AI 辅助重组

> **课程**：《数据采集与清洗》
> **学时**：6 学时（2 理论 + 4 实践）
> **对应单元**：第三单元「检索与生成」
> **使用界面**：① 检索纹样 · ④ 提取纹样 · ② AI 重组创作

---

## 一、这个实验要回答什么

**纹样从「被收藏」到「能被用」，中间缺了什么？**

实验一、二让纹样进了数据库、能被查到。
但「能查到」和「能用」是两件事——
一张绣品照片是查得到的，但它**没法直接用**：
你没法把它印在帆布包上，因为它带着底布和黑边。

**这个实验就做「能用」这一步**：把纹样从照片里提取出来，
让它成为一个可以独立复用的**符号**，然后基于它做重新创作。

---

## 二、预备知识

### 2.1 「符号」的三个特征

一个纹样要能被称为「符号」，必须满足：

| 特征 | 含义 | 本实验怎么实现 |
|---|---|---|
| **可脱离载体** | 不绑定具体物件 | 提取成带透明通道的 PNG |
| **可度量** | 能比较、能计算 | 提取出的形状可做特征统计 |
| **可复用** | 能放到新材料上 | 四方连续拼贴 / AI 重组 |

对照着看：一张绣品照片满足几条？**一条都不满足**。

### 2.2 为什么计算机不能自动判断「什么是纹样」

这是本实验最重要的认知。

人会看到：「这是一朵花，那是底布」。
计算机看到的是：「这些像素是靛蓝，那些像素是朱红」。

**它们中间差的是「语义」**。而语义来自三个方面：

1. **视觉常识**——花是连续的，底布是背景（本实验用**连通域分析**近似）
2. **领域知识**——苗绣的线有自己的纹理特征（本实验用**局部粗糙度**近似）
3. **人的判断**——这张图到底该怎么归类（只能人来）

本实验的算法用前两条做了**近似**，第三条留给实验一的标注。

> **诚实地说**：提取算法能处理大部分情况，
> 但**换一种底布、换一种光照就可能失效**。
> 这不是算法的缺陷，这是「用规则近似语义」这件事本身的边界。
> 学生需要知道**当前方法的适用边界在哪**。

## 三、实验步骤

### 步骤 1：从照片到符号

打开 **④ 提取纹样** 标签页。

1. 左侧选一张**原始图**（推荐先选 `basic_0`，靛蓝底布，效果典型）
2. 点「开始提取纹样」
3. 观察右侧结果

**提取程序做了三件事**，逐个理解：

| 步骤 | 在做什么 | 为什么需要 |
|---|---|---|
| 去黑边 | 裁掉照片四周的纯黑填充条 | 黑边是拍摄/拼接产生的，不是纹样 |
| 估底布 | 从图像外圈统计布的颜色 | 布总是铺到边上的，边上一圈最能代表布色 |
| 分离绣线 | 局部粗糙度 + Otsu 阈值 + 颜色约束 | 绣线比平滑的布更「粗糙」 |

**思考题**：为什么「估底布」要从**图像外圈**统计，而不是全图统计？

> 思路：如果全图统计，纹样本身（彩色绣线）会污染统计结果。
> 而外圈基本是纯底布——这是利用了「布铺到边上」这个**领域常识**。
> **好的算法往往靠的不是更复杂的数学，而是更准确的常识假设。**

### 步骤 2：为什么要用棋盘底看

提取完成后，切到「② 透明纹样（棋盘底）」视图。

**观察并回答**：

1. 为什么背景要放一个**黑白交替的棋盘格**，而不是纯白或纯灰？
2. 找一张花瓣是白色的纹样，看看效果差异

> **这是本实验第一个「啊哈时刻」**：
> 如果背景是纯白，白线花瓣会和背景糊成一片，
> 看起来像「花瓣被挖空了」——学生会误以为算法出错了。
> 棋盘格深浅交替，立刻能区分「真的是透明孔洞」和「白色的绣线」。
>
> **这背后是数据可视化的一个基本原则**：
> 展示结果的背景不能和结果本身同色。

### 步骤 3：从 2D 到 3D

切到「④ 3D 立体展示（可转动）」视图（这是默认视图）。

**操作**：拖动旋转、滚轮缩放。

观察三个调节项：
- **网格精细度**：改分辨率，看细节变化
- **网格密度**：改三角面数量，看曲面平滑度
- **浮雕厚度**：改起伏高度

**思考题**：

1. 3D 视图里的起伏是真实的吗？它是怎么算出来的？
2. 为什么厚度调太大反而**不好看**？

> 第 1 题答案：起伏**不是真实测量**的，而是从**绣线亮度**估算的。
> 亮的地方（受光的线迹）假设更高，暗的地方更低。
> 这是**用 2D 信息反推 3D 结构**，必然有猜测成分。
>
> 第 2 题：厚度过大会把照片噪声也放大成尖刺，
> 所以系统里**刻意不用局部方差/边缘检测**作为高度来源——
> 那会把噪点变成「珊瑚礁」。这是踩过坑之后的取舍。

> **教学要点**：提取出的 3D 是一个**近似模型**，不是真实扫描。
> 让学生明白「数据加工」和「真实测量」的区别，
> 是《数据采集与清洗》的核心素养之一。

### 步骤 4：符号的复用——四方连续

切到「③ 四方连续（2D 图案单元）」视图。

这是把提取出的纹样做**镜像拼贴**，形成可无限延伸的图案。

**观察并回答**：

1. 拼贴用了什么对称方式？（提示：看看拼接处是否连续）
2. 这个图案能用在哪些地方？（举例：布料、壁纸、包装、UI 底纹）

> **这一步是「符号可复用」的直接证明**：
> 一个纹样被提取出来后，可以脱离原来的绣品，
> 变成任何尺度、任何材质上的图案。

### 步骤 5：AI 辅助重组

打开 **② AI 重组创作** 标签页。

**操作流程**：
1. 回 ① 检索纹样，选 1–2 张素材，点「加入我的选择」
2. 回到 ②，确认素材已选中
3. 填**学号 / 姓名**（作品必须记录作者）
4. 选创作模式：单图重组 / 多纹样组合
5. 调**创作强度**：轻微调整 / 中等重组 / 大幅创作
6. 修改或保留**创作描述**
7. 点「开始生成」，然后点「继续等待 / 取回结果」

**关键实验：控制变量**

用**同一张**素材，分别用三种创作强度各生成一次。
把三张结果放在一起对比。

| 强度 | 与素材的相似度 | 新意 | 适用场景 |
|---|---|---|---|
| 轻微调整 | | | |
| 中等重组 | | | |
| 大幅创作 | | | |

**写一段话**：如果你是文创设计师，什么情况下会选哪种强度？为什么？

> **教学要点**：AI 生成不是「一键出好图」。
> **创作强度本质上是一个「保真 vs 创新」的取舍**，
> 而这个取舍是**人的设计判断**，不是算法的默认值。
> 学生必须理解这一点，否则会把 AI 当成黑箱。

### 步骤 6：过程可追溯

生成完成后，打开 **③ 我的作品** 标签页，查看自己的作品。

**记录作品卡片上的所有字段**：

| 字段 | 你的作品实际值 |
|---|---|
| 作品编号 | |
| 学号 / 姓名 | |
| 创作模式 | |
| 创作强度 | |
| 随机种子 | |
| 生成时间 | |
| 来源素材 | |
| 提示词 | |

**思考题**：为什么这些字段都要记录下来？

> 答案涉及**版权与学术诚实**：
> - 「来源素材」——证明作品是**衍生**而非抄袭
> - 「提示词 + 种子」——使结果**可复现**
> - 「时间」——过程性材料，用于教学评价
>
> 这不是可选项，这是 AI 时代创作的**基本规范**。

## 六、教师备课提示

### 本实验的三个认知重点

1. **照片 ≠ 可用的纹样**——需要主动加工
2. **提取是近似，不是测量**——要清楚边界在哪
3. **AI 生成是取舍，不是自动**——强度是设计决策

### 最容易踩的坑

**学生把 3D 视图当「科学测量」**。
要明确说：这是从亮度**估算**的高度，不是真实扫描。
判断学生是否真理解，可以问：
「如果换一张打光完全不同的照片，3D 形状会变吗？」（会变 → 说明是估算）

**学生嫌提取效果不好就想放弃**。
引导他们看步骤 3 的「失败分析」选做题——
**理解方法什么时候失效，比方法本身更重要**。

### 环境准备

| 依赖 | 说明 |
|---|---|
| 提取功能 | 纯本地 CPU 计算，**不需要任何外部服务** |
| AI 生成 | 需要 ComfyUI 或云端 API；**未连接时系统会明确提示，不影响前面步骤** |

> **重要**：如果课堂没有 GPU 环境，
> 步骤 1–4（提取与复用）**完全可以独立完成**，
> 步骤 5–6 可以改为**教师演示**或**课后完成**。

### 时间分配建议

| 环节 | 时长 | 形式 |
|---|---|---|
| 「符号三特征」讲解 | 30 min | 讲授 |
| 步骤 1–3 提取实践 | 90 min | 上机（**核心**） |
| 步骤 4 四方连续 | 30 min | 上机 |
| 步骤 5 AI 重组 | 90 min | 上机 / 演示 |
| 步骤 6 过程追溯 | 30 min | 讲解 + 讨论 |

## 附：本实验的核心概念速查

| 概念 | 一句话解释 | 出现在 |
|---|---|---|
| 连通域 | 相邻的同类像素组成的块 | 提取「保留最大连通块数」 |
| Otsu 阈值 | 自动找最优分割阈值的方法 | 分离绣线 |
| 局部粗糙度 | 小区域内的像素变化剧烈程度 | 判断「这是线还是布」 |
| 棋盘底 | 黑白交替的透明背景指示 | ② 透明纹样视图 |
| 四方连续 | 图案单元镜像拼贴后无限延伸 | ③ 视图 |
| 浮雕高度场 | 每个像素对应一个高度值 | ④ 3D 视图的底层数据 |
| 去噪强度 | 生成时保留多少原图特征 | 创作强度 |
| 随机种子 | 决定生成结果的随机数起点 | 作品可复现 |
